# Astra TV — первая версия

Лёгкий Android TV launcher: домашний экран, часы/дата, список установленных приложений и запуск кнопкой OK.

## Сборка без компьютера
1. Создай репозиторий на GitHub через браузер iPhone.
2. Загрузи в репозиторий всё содержимое этого архива, сохраняя структуру папок.
3. Открой вкладку Actions → Build Astra TV APK → Run workflow.
4. После завершения открой результат запуска и скачай artifact `Astra-TV-debug`.
5. Распакуй ZIP artifact: внутри будет `app-debug.apk`.

## Установка на TCL
Установи APK через приложение для передачи файлов/установки APK на Android TV или через ADB по сети. Разреши установку из неизвестного источника только для приложения, которым открываешь APK. Затем нажми Home и выбери Astra TV.

## Важно
- Это первая базовая версия, не финальный polished-релиз.
- Перед заменой домашнего экрана проверь, что штатный launcher TCL остаётся доступен.
- Если телевизор не предлагает Astra TV как Home app, можно запускать приложение из списка приложений; поведение выбора домашнего приложения зависит от прошивки TCL.
- В этой версии фон — встроенный градиент, а не выбор пользовательских фото; поддержку выбора обоев добавим следующим этапом.

## Обои
Пользовательские обои включены в `app/src/main/res/drawable-nodpi/wallpaper.jpg`.
Чтобы заменить их, положи новое изображение в эту папку под тем же именем `wallpaper.jpg` и пересобери APK.
